QUÉ SE HIZO
1. Allowlist fail-closed en NextAuth mediante BLOG_ADMIN_EMAILS.
   - Si la variable está vacía, nadie puede entrar.
   - Se valida en authorize y en el callback signIn.
   - El login muestra errores claros (AccessDenied, Configuration, etc.).
2. Middleware del CMS corregido.
   - Protege /, /blogs/:path*, /draft y /setting.
   - Redirige a /login.
3. Imagen duplicada corregida.
   - La primera imagen Markdown se muestra como destacada y se quita del cuerpo.
4. Manejo de errores de API.
   - 5xx, red o CMS no configurado -> error boundary (500).
   - Post inexistente -> 404.
   - Ya no aparece "Próximamente" cuando la API falla.
5. Dominio canónico.
   - www.zentt.agency -> 301 -> zentt.agency.
   - sitemap.ts y robots.ts usan NEXT_PUBLIC_PUBLIC_SITE_URL.
6. Noindex.
   - Previews de Vercel y Cloudflare Pages: X-Robots-Tag noindex, nofollow.
   - CMS completo: noindex, nofollow.
7. Rebranding mínimo del CMS.
   - "ZENTT BLOG" en lugar de "ADMIN".
   - Sin foto personal ni datos de ejemplo.
   - Categorías y tags de alojamiento/turismo/reservas.
8. SEO.
   - /blog, /blog/[slug], /blog/categoria/[category], /blog/etiqueta/[tag].
   - Metadata, canonical, Open Graph, JSON-LD Article.
   - Sitemap y robots.
   - Enlaces en navbar y footer.
9. Documentación.
   - documentation/cambios_1.md
   - resumen-sesion.txt
   - Copia en saas/web/frontend/documentation/.
