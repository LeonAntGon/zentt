OBJETIVO
Publicar el blog corporativo de Zentt en https://zentt.agency/blog, con un CMS privado independiente, MongoDB Atlas como base de contenido y SEO correcto.

ESTRUCTURA FINAL
- Frontend público: saas/web/frontend (repo git "zentt").
- CMS de Zentt: blog-sistem/zentt-blog-admin (carpeta nueva, proyecto independiente, sin repo propio por ahora).
- Vida Fuerte: blog-sistem/vida-fuerte--Full-Stack-Blog-Platform (proyecto original, restaurado e intacto en el commit 4b36bcc).

QUÉ SE HIZO
1. Seguridad y autenticación
   - Allowlist fail-closed con BLOG_ADMIN_EMAILS.
   - Si la variable está vacía, nadie puede entrar.
   - Validación en authorize y en el callback signIn.
   - Login con mensajes claros para AccessDenied, Configuration y OAuth.
   - Middleware del CMS protege /, /blogs/:path*, /draft y /setting.
   - CMS con X-Robots-Tag noindex, nofollow.
   - Previews de Vercel/Cloudflare con noindex, nofollow.
   - API pública sin borradores; respuestas autenticadas con no-store.

2. API y datos
   - GET /api/blogapi?public=true solo devuelve publicados.
   - Validación de estados draft/publicado.
   - Códigos HTTP correctos: 201, 400, 401, 404, 405, 500.
   - Índices MongoDB para slug, status, categorías y tags.
   - Conexión a MongoDB cacheada.
   - Cache pública de 5 minutos con Vary: Cookie.
   - El CMS tolera el build sin MONGODB_URI y falla cerrado en runtime.

3. UI del panel
   - "ZENTT BLOG" en lugar de "ADMIN".
   - Sin foto personal; avatar de la cuenta o inicial.
   - Configuración sin datos de ejemplo.
   - Categorías de alojamiento/turismo.
   - Tags de reservas, marketing, WhatsApp, temporada, atención y rentabilidad.

4. SEO del sitio público
   - /blog, /blog/[slug], /blog/categoria/[category], /blog/etiqueta/[tag].
   - Metadata, canonical, Open Graph y JSON-LD Article.
   - Sitemap y robots.
   - 301 de www.zentt.agency a zentt.agency.
   - Enlaces al blog en navbar y footer.
   - Imagen destacada sin duplicarse en el cuerpo.

5. Infraestructura
   - El CMS se separó de Vida Fuerte y quedó en blog-sistem/zentt-blog-admin.
   - Vida Fuerte se restauró a su estado original (4b36bcc).
   - El frontend antiguo de Vida Fuerte no se usa para Zentt.
   - BLOG_API_URL es server-only y apunta al CMS de Zentt.

6. Documentación
   - documentation/cambios_1.md
   - resumen-sesion.txt
   - Copia versionada en saas/web/frontend/documentation/.
   - README propio del CMS en blog-sistem/zentt-blog-admin/README.md.

CÓMO SE CONECTA CON ZENTT.AGENCY
1. El editor publica en el CMS de Zentt.
2. El post se guarda en MongoDB Atlas.
3. El frontend público consulta ${BLOG_API_URL}/api/blogapi?public=true.
4. El contenido aparece en https://zentt.agency/blog.
